# 처리 파이프라인

`simulate_source`(`src/scan_sim/pipeline.py`)가 1~15단계를 고정 순서로 실행하고,
`process_file`(`batch.py`)이 16단계 인코딩을 한다. 단위와 색 영역 결정은
[ADR-002](../decisions/ADR-002-units-and-order.md)에 있다.

## 표현

- 1~6단계: working 해상도(600 dpi)의 float32 RGB. 프린터는 **토너 흡수율** `A`
  (0 = 맨 종이, `black_density` = 단색 검정)로, 종이는 **반사율**로 표현한다.
- 7~12단계: linear-light 반사율 또는 센서 신호.
- 13~15단계: 스캐너 출력 sRGB 값(0~1). 마지막에 8비트로 반올림한다.
- 중간에 JPEG 재압축이나 8비트 변환은 없다.

## 단계

| # | 모듈 | 모델 |
| --- | --- | --- |
| 1 | `io`, `pdf` | PDF는 PDFium으로 해당 페이지를 흰 바탕에 working DPI로 바로 렌더링한다. 이미지는 Pillow로 읽고 EXIF 회전을 적용한다. 투명 영역은 흰 종이로 합성한다. 파일 DPI(없으면 `assumed_dpi`)로 페이지 크기를 검사한 뒤 linear-light로 바꿔 working DPI로 보간한다. 확대는 보간만 하고 디테일을 만들지 않는다 |
| 2 | `printer` | 프린터 색 행렬 → 반사율^gamma → `A = (1 − R) × black_density` |
| 3 | `printer` | `A`에 비등방 가우시안 PSF를 적용한다 |
| 4 | `printer` | 가장자리 이동, 톤 dot gain, 토너 농도 얼룩(아래 설명). `A`는 단색 검정 농도를 넘지 않는다 |
| 5 | `paper` | `base_rgb × (1 + 저주파 + 섬유 + 미세 입자)`에 채널별 작은 색 변화를 더한다. 질감은 세 채널이 약 0.95 상관을 갖고, 섬유는 한 축으로 길다 |
| 6 | `paper` | `out = paper × (1 − A)`. 흰 영역에도 종이 질감이 남고, 토너 영역은 토너 얼룩을 가진다 |
| 7 | `geometry` | 회전·축척·이동·모서리 원근을 호모그래피 하나로 합쳐 한 번 warp한다. 드러난 영역은 덮개 색(`base_rgb`)이다 |
| 8 | `scanner` | 스캐너 DPI로 재샘플링한다(기본 `area` = 화소 면적 적분) |
| 9 | `scanner` | 광학 PSF. y(용지 진행 방향)가 보통 더 넓다 |
| 10 | `scanner` | `1 + 1·2차 다항식 + 저주파 필드 − falloff·x⁴`을 곱한다 |
| 11 | `scanner` | 줄별 이득(색별), 소자별 이득(세 색 공통), 읽기 노이즈와 √신호에 비례하는 shot 노이즈 |
| 12 | `scanner` | 스캐너 색 행렬 × 화이트 밸런스 |
| 13 | `scanner` | sRGB 인코딩 → 배경 날리기 → `black + (white − black) × v^gamma` |
| 14 | `scanner` | 언샤프 마스크 `v + amount(v − blur)`, 0~1로 자른다 |
| 15 | `artifacts` | 확률적으로 세로줄(가우시안 단면의 어두운 열)과 가로 띠(1차원 저주파 이득) |
| 16 | `encoding` | JPEG(품질 범위, 4:2:0) 또는 PNG를 한 번만 인코딩하고 DPI를 기록한다 |

## 토너 가장자리 모델 (4단계)

형태학적 팽창(dilation)은 가장자리를 정수 픽셀 단위로 옮겨 부자연스럽다. 대신
가장자리를 거리 `d`만큼 옮기면 그 위치 값이 약 `d × |∇A|`만큼 변한다는 1차 근사를 쓴다.

```text
A ← A + (radius + roughness × field) × |∇A|
```

- `|∇A|`는 PSF 뒤의 부드러운 가장자리에서만 0이 아니다. 그래서 흰 종이와 단색 면은
  건드리지 않고 가장자리만 움직인다. 이동 거리가 1픽셀보다 작아 1차 근사로 충분하다.
- `field`는 상관 길이 0.8 W px(약 34 µm, 토너 입자가 만드는 들쭉날쭉한 가장자리 규모)의
  단위 분산 랜덤 필드다. 가장자리 위치만 흔들고 글자 모양은 바꾸지 않는다.
- 톤 dot gain: `c = A / black_density`일 때 `A += strength × black_density × c(1 − c)`.
  옅은 음영과 안티앨리어싱 픽셀은 진해지고 단색 검정과 종이는 그대로다.
- 마지막에 `A`를 `[0, black_density]`로 자른다. 자르지 않으면 얇은 선의 가장자리가
  단색 면보다 진해져 이중선처럼 보인다(구현 중 확인한 결함).

## 랜덤 필드

`noise.smooth_field`는 평균 0, 분산 1의 가우시안 랜덤 필드다. 상관 길이가 3 px 이상이면
거친 격자에서 만든 뒤 확대한다. 그래서 1000 px 규모 얼룩도 비용이 작다. 단계별 난수
스트림은 [ADR-003](../decisions/ADR-003-seeds.md)을 따른다.

## 메모리와 속도

A4 600 dpi working 이미지(4960×7016 RGB float32)는 약 420 MB다. 중간 배열을 포함하면
프로세스 하나의 최대 메모리는 약 2.4 GB다. A3는 약 두 배다. 측정값은
[VALIDATION](../ops/VALIDATION.md)에 있다. 타일 분할은 경계 결함 위험 때문에 쓰지 않는다.
