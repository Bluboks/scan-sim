# ADR-002: 단위, 해상도, 색 영역, 단계 순서

- 상태: ACCEPTED
- 날짜: 2026-10-02
- 결정 주체: 에이전트(위임)

## 배경

명세는 단계 순서를 고정하지만 픽셀 단위 파라미터가 어느 해상도 기준인지는 정하지
않았다. 또 명세 순서는 "300 dpi로 재샘플링 → 스캐너 흐림"인데, 실제 물리 현상에서는
광학 흐림이 먼저 생기고 그다음에 센서가 샘플링한다.

## 결정

- 프린터와 종이 파라미터(`printer.*`, `paper.*`)는 working 해상도(기본 600 dpi) 픽셀
  단위다. 인쇄물의 성질이기 때문이다.
- 스캐너와 배치 파라미터(`scanner.*`, `geometry.translation_px`, `artifacts.*`)는
  스캐너 해상도 픽셀 단위다. 사용자가 결과 이미지에서 보는 단위이기 때문이다.
- 명세의 단계 순서를 그대로 지킨다. 스캐너 PSF는 재샘플링 뒤에 스캐너 픽셀 단위로
  적용한다. 재샘플링 기본값 `area`는 센서 화소의 면적 적분(박스 필터)에 해당하므로,
  "면적 적분 + 가우시안"이 실제 광학계 흐림과 화소 개구를 근사한다.
- 색 영역: 입력 sRGB를 linear-light로 바꾼 뒤 working DPI로 재샘플링한다. 프린터부터
  색 보정까지(2~12단계)는 linear-light에서 계산한다. 13단계에서 sRGB로 인코딩하고,
  톤 곡선·배경 날리기·샤프닝·잡티는 인코딩 값에서 처리한다. 스캐너 영상처리기가
  출력 영역에서 동작하는 방식과 같다.
- 배치 오차(회전·축척·이동·원근)는 한 번의 호모그래피 변환(평면 원근 변환)으로
  합쳐 working 해상도에서 한 번만 보간한다.

## 이유·trade-off

광학 흐림을 재샘플링 앞에 두면 에일리어싱(계단 무늬)이 조금 줄어드는 대신 명세 순서와
달라진다. PSF 시그마가 0.25~0.75 스캐너 픽셀 수준이라 두 방식의 차이는 작고, 명세
순서를 지키는 쪽을 택했다. 스캐너 PSF 단위가 스캐너 픽셀이므로 `scanner.dpi`를 바꾸면
물리적 흐림 폭도 함께 바뀐다. 이 점은 [CONFIG](../reference/CONFIG.md)에 적었다.

## 후속

실물 캘리브레이션 때 PSF를 재샘플링 전에 적용하는 방식이 실측에 더 맞으면 이 결정을
대체한다.
